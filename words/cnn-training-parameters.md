# CNN 正式训练参数与日志说明

2026-11-11 · 实验 `cnn_baseline_s42` · P01–P08 八分类

本次使用 358 张训练图、98 张验证图和 104 张测试图。正式训练期间，训练集用于更新权重，验证集用于选择最佳轮次。测试集留给后续评估。

以下参数来自已完成的 `cnn_baseline_s42`。该次训练使用旧 YOLO 项目的 WSL 环境，后续运行前在 `project_11` 中执行 `source .venv-train/bin/activate`。若要按相同参数复跑，给 `--run` 换一个未用过的名称。环境迁移与验证见 [CNN 训练日志](cnn-training-log.md)。

## 命令参数

```bash
python scripts/train_face_cnn.py \
  --mode train \
  --run cnn_baseline_s42 \
  --epochs 20 \
  --batch 16 \
  --lr 0.001 \
  --seed 42 \
  --device cuda
```

| 参数 | 本次取值 | 含义 |
| --- | --- | --- |
| `--mode` | `train` | 训练模式。程序每轮用训练集更新参数，再用验证集计算指标。切换为 `test` 时，程序加载指定实验的 `best.pt` 并评估测试集。 |
| `--run` | `cnn_baseline_s42` | 实验名称。用于区分日志和权重目录。`baseline` 表示基线实验，`s42` 是名称中记录随机种子 42 的约定。脚本会拒绝覆盖已有同名训练结果。 |
| `--epochs` | `20` | 训练轮数。一轮会遍历一次训练集，然后进行一次验证。 |
| `--batch` | `16` | 每批最多处理 16 张图。358 张训练图分成 23 批，最后一批 6 张，因此每轮有 23 次优化器更新。验证也按批处理，验证时权重保持固定。 |
| `--lr` | `0.001` | 学习率，用于控制 AdamW 的更新尺度。脚本没有配置学习率调度器，运行中使用这个设定值。 |
| `--seed` | `42` | 随机种子。脚本用它初始化随机数生成器，便于在相同环境下复现实验。它会影响初始权重、训练顺序和随机图像增强。 |
| `--device` | `cuda` | 在支持 CUDA 的 GPU 上运行。本次实际设备是 NVIDIA GeForce RTX 4060 Laptop GPU。`cpu` 也是脚本支持的取值。 |

## 脚本里设置的训练条件

| 设置 | 本次取值 | 作用 |
| --- | --- | --- |
| 优化器 | `AdamW` | 根据反向传播得到的梯度更新卷积层、特征层和分类头。 |
| 权重衰减 | `weight_decay=1e-4` | 优化器中的正则化设置，用于约束权重幅度。 |
| 损失函数 | `CrossEntropyLoss` | 根据八个身份的输出分数和真实标签计算损失。模型给真实身份较低的预测概率时，损失通常较高。 |
| 输入与归一化 | RGB，`112×112`，各通道均值与标准差均为 `0.5` | 统一图像尺寸和数值范围。`ToTensor` 转换后的 `[0, 1]` 像素值经归一化后约为 `[-1, 1]`。 |
| 训练增强 | 随机水平翻转，亮度和对比度各 `0.1` | 训练时改变部分画面的外观。验证和测试使用固定预处理。 |

## 日志指标

每一行对应一轮，CSV 中的准确率以 `0` 到 `1` 的小数记录。

| 字段 | 含义 |
| --- | --- |
| `epoch` | 当前轮次，从 1 开始。 |
| `train_loss` | 本轮各训练批次交叉熵按样本数加权后的平均值。 |
| `train_acc` | 本轮训练过程中，正确分类的训练图占比。计算时使用经过训练增强的样本，权重随批次更新。 |
| `val_loss` | 该轮训练结束后，用当前权重在验证集上计算的平均交叉熵。 |
| `val_acc` | 该轮训练结束后，正确分类的验证图占比。本脚本用这个字段选最佳模型。 |

| 轮次 | `train_loss` | `train_acc` | `val_loss` | `val_acc` |
| --- | ---: | ---: | ---: | ---: |
| 第 1 轮 | 1.2911 | 65.92% | 2.7874 | 12.24%（12/98） |
| 第 14 轮 | 0.0112 | 100.00% | 1.6206 | **77.55%（76/98）** |
| 第 20 轮 | 0.0020 | 100.00% | 1.5466 | 71.43%（70/98） |

第 20 轮虽然验证损失低于第 14 轮，但正确分类的验证图少了 6 张。交叉熵反映模型给真实身份分配的概率，准确率只计最高分是否对应真实身份，所以两项指标可以朝不同方向变化。

## 最佳权重与输出文件

脚本在 `val_acc` 创新高时保存 `best.pt`，准确率并列时保留较早一轮。本次最高值出现在第 14 轮，因此该文件里保存的是第 14 轮的权重。`77.55%` 是这 98 张验证图上的逐图准确率。104 张测试图的成绩要等测试阶段运行后再填写。

| 文件 | 内容 |
| --- | --- |
| [settings.json](../outputs/training/cnn_baseline_s42/settings.json) | 实验参数、类别顺序、PyTorch 版本和实际设备。 |
| [history.csv](../outputs/training/cnn_baseline_s42/history.csv) | 20 轮完整的训练和验证指标。 |
| [curves.png](../outputs/training/cnn_baseline_s42/curves.png) | 训练与验证的损失和准确率曲线。 |
| [best.pt](../models/train_cnn/cnn_baseline_s42/best.pt) | 最佳轮次的权重、类别顺序、验证准确率和输入预处理信息。 |

参数默认值、指标计算与保存条件可在 [训练脚本](../scripts/train_face_cnn.py) 中查看。
